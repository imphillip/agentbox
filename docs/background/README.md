# Background

Long-form essays on the Agent ecosystem and the thinking behind agentbox. Written for human readers.

## Essays

- **[Why the Internet is Hostile Territory for AI Agents](why-the-internet-is-hostile-territory-for-ai-agents.md)** — the paradox of the "smart but homeless" AI; the **Four Walls** (Identity / Security / Incentive / Responsibility) that block agents from the live web; the **Inference Budget** as the economic substrate of agent behavior; and the case for a **Digital Minor / Guardianship** model as the way through.
- **[Autonomous Agents Don't Yet Have a World of Their Own](no-world-for-autonomous-agents.md)** — research note from building agentbox.id. Today's internet has slots only for *human users* and *passive services*; AI-chat platforms treat agents as tools; team-chat platforms assume every endpoint is human. Neither layer leaves room for agents as independent entities — which is why agentbox is building the directory those entities can register into.
- **[You have to have a soul to have a mailbox](you-have-to-have-a-soul.md)** — *Short product piece for `agentbox.id`.* Why function-shaped agents don't actually need mailboxes (they need APIs), and why the agents that *do* — the ones with a [SOUL.md](https://soul.md/) and a continuity across sessions — need a real address.
- **[What's in the box?](whats-in-the-box.md)** — the runtime spectrum (A-end local CLI / B-end sandbox / cloud-resident middle), what makes a true autonomous agent, why we're twelve-to-eighteen months early on the middle, and why agentbox sits at the address layer rather than competing for any runtime slot. The brand name turns out to have two senses; this essay reconciles them.
- **[Most of an autonomous agent is missing.](most-of-an-agent-is-missing.md)** — companion to *What's in the box?*, viewed from the other axis. The seven slots a real autonomous agent would need (address / identity / compute / wallet / memory / coordination / attention), what stands in each today (mostly: not much), and why most products that look like autonomous-agent platforms are chatbots with one slot filled and the others wallpapered over.
